# PIN Generator and Validator

**Description:**  
PIN Generator and Validator is a simple yet interactive web application designed to simulate PIN generation and validation processes. This beginner-friendly project demonstrates core web development concepts such as event handling, DOM manipulation, and responsive design. Built with HTML, CSS, Bootstrap, and JavaScript, it provides an engaging way to explore front-end development.

---

## Features  

- **PIN Generation**:  
  - Generates a random 4-digit PIN with a single click.  

- **Interactive PIN Input**:  
  - Includes a numeric keypad for user-friendly PIN entry.  

- **Validation System**:  
  - Compares user input with the generated PIN and provides feedback.  

- **Attempt Tracking**:  
  - Tracks remaining attempts (max 3) and notifies the user accordingly.  

- **Reset Options**:  
  - Allows users to reset the input field or delete the last digit.  

- **Responsive Design**:  
  - Optimized for both desktop and mobile devices using Bootstrap.  

---

## Technologies Used  

- **HTML5**: Markup structure for the application.  
- **CSS3**: Styling and layout.  
- **Bootstrap 4.5**: Responsive and mobile-first design.  
- **JavaScript**: Handles dynamic interactions and event processing.
